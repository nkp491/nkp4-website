# NKP4 Website — Start Here

## Install into your website repo

Copy the entire folder:

`docs/nkp4-site/`

into the root of the NKP4 website repository so the final path is:

```text
<repo>/docs/nkp4-site/
```

Then open Codex from the repository root and use:

`docs/nkp4-site/10-CODEX-HANDOFF-PROMPT.md`

as the initial prompt.

## Recommended workflow

1. Let Codex read all context files.
2. Ask it to audit the existing site first.
3. Review its proposed information architecture and homepage narrative.
4. Approve or adjust the direction.
5. Implement one section at a time.
6. When a new factual decision is made, update the appropriate context file before continuing.

This keeps the website and future coding agents aligned with the same source of truth.
