# NKP4 Website Context

This folder is the source of truth for the NKP4 website.

It exists so designers, developers, Codex, Claude Code, and other agents can understand NKP4 before making product, copy, or design decisions.

## Primary rule

**Do not treat NKP4 like a generic holding-company website.**

NKP4 is a founder-led holding company, portfolio, operating platform, and professional home for the companies, services, investments, and ideas associated with Nielsen Aragon.

The website's primary job is to create **quiet credibility**.

Someone should be able to discover Nielsen through social media, meet him at a conference, hear him speak, receive an introduction, or meet him while networking and then visit one credible destination that explains:

- who he is
- how he got here
- what he has built
- what he currently operates
- what he invests in
- what services are available
- how to contact him

The site is not intended to show off. It should document the work clearly enough that the work speaks for itself.

## Authority

When files conflict, use this priority:

1. Explicit factual statements in `03-COMPANY-STRUCTURE.md` and `05-PORTFOLIO.md`
2. Positioning in `01-WEBSITE-BRIEF.md`
3. Nielsen's voice and story in `02-FOUNDER-STORY.md`
4. Tone rules in `07-CONTENT-RULES.md`
5. Design references in `06-DESIGN-REFERENCES.md`

Never invent portfolio ownership, investment relationships, customer counts, revenue, partnerships, or credentials that are not documented here.

## Central ideas

### Build. Operate. Equip. Invest.

NKP4 can create companies, operate businesses, equip founders and operators with modern resources, and invest where it can contribute more than capital.

### Accountability → Predictability → Profitability → Scalability

This is a core operating formula developed from Nielsen's experience.

### Don't just sell the apple. Sell the seeds.

The visible companies are the fruit. The deeper value is the knowledge, systems, technology, pattern recognition, operating experience, and resources that can be planted repeatedly in new businesses.
